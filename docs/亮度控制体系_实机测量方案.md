# 全新亮度调节设计方案 — 实机测量方案

> 适用：屏幕峰值 1000–1500 nit（f_backlight Mode A）、HDMI 图案发生器、CA-410 多探头、可控光照环境。
> 目的：验证文档《全新亮度调节设计方案》中各项亮度映射公式与模式行为在实机上的符合性，覆盖 SDR/HDR 参考白锚定、f_backlight 曲线、L_screen_max 映射、BT.2390 TMO 反解、图像模式偏转、环境光响应、OSD 压缩、功率能效。

---

## 1. 测试设备与环境

| 设备 | 用途 | 要求 |
|---|---|---|
| CA-410 多探头 | 屏幕亮度测量 | 至少 2 路（中心 + 边缘），预热 30 分钟，按说明书校零 |
| HDMI 图案发生器 | 精确输出 PQ / SDR 码值测试图 | 10bit 或 12bit，支持 Rec.2100 PQ、BT.709/BT.2020 SDR、可设窗口大小与位置 |
| 可调光源（照度计校准） | 环境光传感器激励 | 0–2000 lux 可调，均匀照射电视环境光传感器位置，用照度计同步记录 lux |
| 功率计 | 能效/功耗测试 | 采样 ≥1 Hz，精度 ±0.1W |
| 暗室 | 隔绝杂光 | 环境漏光 < 1 lux（关灯状态） |

**测试前准备**：
1. 电视恢复出厂设置，升级到待测固件版本；
2. 关闭：自动亮度、True Tone 类、动态对比度、运动补偿、Peaking（除专门测试项外）；
3. 白点校准 6500K（D65）确认；
4. CA-410 探头贴屏幕中心，环境光传感器位置用照度计标定可调光源的实际 lux 值；
5. 预热：电视播放高亮动态内容 30 分钟（稳定背光温度）。

## 3. 测试用例

### 用例 A — SDR/HDR 参考白等价锚定

**验证**：F.5 节，SDR 86% 白与 HDR 203 nit 在相同图象模式/背光亮度下呈现亮度相等。

**前置**：图象模式=标准、背光亮度 UI=50（中点，f_backlight(50)=203）、环境光关闭。

| 步骤 | 信号 | 测量 | 记录 |
|---|---|---|---|
| A1 | HDR 全屏 203 nit PQ（code 594） | 中心 10% 窗口亮度 | L_hdr_203 |
| A2 | SDR 全屏 86% 白（code 954） | 中心 10% 窗口亮度 | L_sdr_86 |
| A3 | SDR 全屏 100% 白（code 1023） | 中心 10% 窗口亮度 | L_sdr_100 |

**判定**：|L_hdr_203 − L_sdr_86| / L_hdr_203 ≤ 5%（等价锚定）；L_sdr_100 ≈ L_hdr_203 × 1.228（F.7 γ 映射）。

**重复**：背光亮度 UI=25、75 各做一组，确认锚定在不同全局亮度下仍成立。

### 用例 B — f_backlight 曲线（UI → 参考白亮度）

**验证**：F.6.2 节，背光亮度 UI 0–100 → L_ref_white 映射曲线（Mode A：中点锚 203、C² 连续）。

**前置**：图象模式=标准（G_mode=1）、环境光关闭、信号=HDR 203 nit PQ。

| 步骤 | UI 背光亮度 | 测量 | 预期（L_scr_max=1000 nit 示例） |
|---|---|---|---|
| B1 | 0 | L_ref_white | 50 nit（L_rw_min，固定） |
| B2 | 25 | L_ref_white | ≈94 nit |
| B3 | 50 | L_ref_white | **203 nit**（中点锚定，核心） |
| B4 | 75 | L_ref_white | ≈370 nit |
| B5 | 100 | L_ref_white | ≈600 nit（L_rw_max = 0.6×1000） |

**判定**：
- B1 = 50 ±3 nit；B3 = 203 ±5%；B5 与公式 L_rw_max 误差 ≤5%；
- 中间点与 f_backlight 曲线（F.6.2.1）采样表对比，偏差 ≤5%；
- UI 50 处曲线 C² 连续（实测 B2/B3/B4 三点拟合，无折角）。

**扩展**：L_scr_max=1500 nit 机型重做 B5（L_rw_max 封顶=800）。

### 用例 C — L_ref_white → L_screen_max 映射（log-PCHIP）

**验证**：F.8.1 节，参考白亮度 → 屏幕峰值亮度的对数三次 Hermite 映射。

**前置**：环境光关闭、图象模式=标准、信号=HDR 10% 窗口 4000 nit PQ（code 949）。

> 测 L_screen_max 的方法：播放 HDR 10% 窗口接近满量程信号（4000 nit 或 10000 nit PQ），实测窗口亮度 = 当前 L_screen_max。

| 步骤 | UI 背光亮度（→L_ref_white） | 先测 L_ref_white（203信号） | 再测 L_screen_max（10%窗口 4000nit信号） |
|---|---|---|---|
| C1 | 0 | 50 | 预期 200（L_scr_min 固定） |
| C2 | 25 | ≈94 | 预期 ≈480 |
| C3 | 50 | 203 | **预期 v203 = r × L_scr_max**（L_scr_max=1000 时 r=0.8 → 800） |
| C4 | 75 | ≈370 | 预期 ≈905 |
| C5 | 100 | ≈600 | 预期 = L_scr_max（满量程） |

**判定**：
- C1 = 200 ±10 nit；C3 = r×L_scr_max ±5%（核心中点锚）；C5 = L_scr_max ±3%；
- 全 5 点与 F.8.1 示例表对比偏差 ≤5%；
- 头空间比率 ρ_eff(203) = L_screen_max(203) / 203，记录并与文档预期（1000nit 屏 ≈3.9×）对比。

### 用例 D — BT.2390 TMO 反解与 roll-off 形状

**验证**：F.8.2 节，203 nit 输入严格映射到 L_ref_white；F.8.3 EETF 曲线形状（拐点以上 roll-off、不硬切）。

**前置**：环境光关闭、图象模式=标准、UI=50（L_ref_white=203）。

**D-1 参考白精确映射**：播放 HDR 全屏 203 nit PQ，测中心亮度 → 应 = 203 ±2 nit（反解收敛精度 0.1%）。

**D-2 灰阶曲线扫描**：播放 33 级灰阶（每级用 10% 窗口或全屏，记录每级实测亮度），绘制输入码值→输出亮度曲线。

| 输入 nit | 预期输出（L_ref_white=203, L_scr_max=1000） |
|---|---|
| 0–拐点（≈350） | 1:1 直通（out = in，偏差 ≤3%） |
| 500 | roll-off 开始，out < in |
| 1000 | 接近 L_TMO_target |
| 4000 | 接近 L_screen_max |
| 10000 | = L_screen_max（封顶） |

**判定**：
- 拐点以下 1:1（实测斜率 1.0 ±3%）；
- 拐点以上单调递增、无过冲（无"越亮越暗"）；
- 203 精确映射、10000 封顶 L_screen_max；
- 曲线与 BT.2390 EETF（F.8.3）理论值对比，PQ 域偏差 ≤3%。

**D-3 不同 UI 下的曲线族**：UI=25、50、75 各做一组灰阶扫描，确认曲线随 L_ref_white 整体平移、203 始终精确锚定。

### 用例 E — 图像模式角度偏转

**验证**：F.3 节，鲜艳/标准/影院/壁纸模式通过角度偏转 Δθ_mode 改变 G_mode。

**前置**：环境光关闭、UI 背光亮度=50、信号=HDR 203 nit PQ。

| 步骤 | 图象模式 | 测 L_ref_white | 预期 G_mode | 预期 L_ref_white（标准=203） |
|---|---|---|---|---|
| E1 | 标准 | L_std | 1.0 | 203（基线） |
| E2 | 鲜艳 | L_vivid | >1（+8~12°） | >203（更亮） |
| E3 | 影院 | L_cinema | <1（−6~10°） | <203（更暗） |
| E4 | 壁纸 | L_wallpaper | 最小（−20~30°） | 最低 |

**判定**：
- G_mode = L_mode / L_std，与文档 Δθ_mode→G_mode 公式对比 ≤5%；
- 壁纸模式 L_ref_white 不超过 L_max_wallpaper（模式上限钳制）；
- 切换模式时 203 锚点跟随 G_mode 缩放（不是固定 203）。

**扩展**：每个模式内调"亮度增益"UI 0/50/100，确认 Δθ_mode 线性映射（F.6.1）。

### 用例 F — 环境光响应曲线

**验证**：F.4 主公式 ambient on 分支；F.6.2.3 S_bl 缩放与 UI 自动回跟。

**前置**：开启"环境光调整屏幕亮度"功能、图象模式=标准。

**F-1 环境光→参考白亮度曲线**：UI 背光亮度=50（S_bl=1.0 初始）。

| 步骤 | 环境光 lux（可调光源） | 测 L_ref_white（HDR 203信号） | 预期 |
|---|---|---|---|
| F1 | 0 | L(E=0) | >0（E_offset 保证基础亮度） |
| F2 | 100 | L(E=100) | 随 E 升高 |
| F3 | 300 | L(E=300) | 典型观看环境锚点 |
| F4 | 1000 | L(E=1000) | 接近上限 |
| F5 | 2000 | L(E=2000) | 钳制在 L_max_mode |

**判定**：曲线单调递增；0 lux 不为零；高 lux 钳制生效；与 f(E) 形状函数（PQ 调校的 γ）定性一致。

**F-2 S_bl 缩放与 UI 回跟**：
1. 固定环境光 300 lux，记录 UI 显示值；
2. 用户手动拖 UI 到 75，记录新的 L_ref_white；
3. 计算 S_bl = L_ref_white(新) / L_ref_white(300lux裸值)，应与图象模式无关；
4. 改变环境光到 100/1000 lux，观察 UI 自动回跟（动作 1）；
5. 确认 S_bl 被记忆（切回 300 lux 时 L_ref_white 沿已缩放曲线）。

**判定**：S_bl 在不同图象模式（标准/影院）下相同（G_mode 约掉）；UI 随环境光自动更新且无模式漂移。

### 用例 I — 动态电影画面中嵌入固定小窗口测量

**验证目标**：静态窗口测试（用例 B/C/D）验证的是屏幕在恒定信号下的亮度能力上限；而真实动态画面里，背景 APL 随镜头实时变化，TMO 曲线和背光亮度都在动态响应。本用例在**实时播放的电影画面上叠加一个固定位置、固定亮度的测量小窗口**，验证：

1. **内容亮度稳定性**：同一目标亮度（如 203 nit）在不同背景 APL 的镜头下，实测亮度是否稳定——验证文档核心承诺"画面变化（APL 变化）不会引起内容亮度的无序变化"；
2. **TMO 联动正确性**：背光随 APL 变化时，TMO 曲线是否同步更新，保证 203 nit 内容始终精确映射到 L_ref_white；
3. **时域响应**：切镜头瞬间（APL 突变），小窗口亮度恢复到目标值的时间（attack/release）是否可接受，有无过冲振荡。

#### 测量窗口规格

| 参数 | 值 | 说明 |
|---|---|---|
| 窗口大小 | **5% 面积**（约 880×880 px @4K） | 足够大让 CA-410 探头稳定读取；足够小不显著改变整体 APL |
| 窗口位置 | **屏幕中心** | 探头固定对准 |
| 窗口亮度 | **203 nit PQ（code 594）** | 参考白——验证核心锚点稳定性 |
| 窗口背景 | 实时电影画面（PQ HDR 片源） | 提供动态 APL |

> 备选窗口亮度档：100 nit（code 520，暗部锚）、1000 nit（code 766，高光锚），用于验证不同亮度层级在动态画面下的稳定性。

#### 测试片源选择

选取 APL 变化幅度大的电影片段，覆盖以下场景类型（每段约 2–3 分钟）：

| 片段类型 | APL 特征 | 典型镜头 | 验证重点 |
|---|---|---|---|
| 暗场→亮场突变 | APL 5%→40% | 夜景切白天、室内切室外 | 切镜头瞬间 203 是否跳变 |
| 亮场→暗场突变 | APL 40%→5% | 白天切夜景 | release 恢复时间、无拖尾 |
| 持续高 APL | APL ≈50% | 雪地、沙漠、白墙 | 高 APL 下 203 是否被 ABL 压低 |
| 持续低 APL | APL ≈5% | 暗夜、洞穴 | 低 APL 下 203 是否被异常抬升（Boost 联动验证） |
| 高频切换 | APL 快速波动 | 动作戏、闪电、爆炸 | 时域稳定性、无振荡 |
| 渐变 | APL 缓慢变化 | 日出/日落、淡入淡出 | 曲线平滑跟踪、无阶梯 |

> 片源需为 PQ HDR 编码（Rec.2100 / ST 2084），分辨率匹配电视原生（4K）。推荐准备 2–3 部不同风格的电影各取一段。

#### 测量方法

**前置**：图象模式=标准、UI 背光亮度=50（L_ref_white=203 目标）、环境光关闭、CA-410 探头固定对准屏幕中心小窗口位置、电视预热完成。

**I-1 参考白动态稳定性（核心）**：

1. 图案发生器输出：**电影画面（HDMI 播放） + 中心 5% 窗口 203 nit PQ 叠加**；
2. CA-410 设为连续记录模式（采样 ≥10 Hz），同步录制小窗口亮度时间序列 L(t)；
3. 播放全部 6 类测试片段，记录完整 L(t) 曲线；
4. 每段片段提取：均值 L̄、标准差 σ、最大值 L_max、最小值 L_min、切镜头瞬间过冲幅度与恢复时间。

**判定**：
- 全段 L̄ 与目标 203 nit 偏差 ≤5%（即 193–213 nit）；
- σ / L̄ ≤ 5%（单段内波动小，内容亮度稳定）；
- 切镜头瞬间 L(t) 偏离目标 ≤10% 且在 200ms（attack）/ 800ms（release）内恢复（与文档时域参数一致）；
- 无持续振荡（波动频率 >3Hz、幅度 >5% 视为不合格）。

**I-2 不同亮度档的动态稳定性**：

将窗口亮度改为 100 nit / 1000 nit，重复 I-1（至少取暗场→亮场、亮场→暗场、高频切换三段），确认：
- 100 nit（暗部）：低 APL 场景下不被异常抬升（验证"低亮度内容不被 Boost 拉至不合理超高亮度"）；
- 1000 nit（高光）：高 APL 场景下 roll-off 正确、不硬切（保留层次）。

**I-3 不同模式/UI 下的动态稳定性**：

| 变量 | 取值 | 验证 |
|---|---|---|
| 图象模式 | 标准 / 影院 / 鲜艳 | G_mode 下 203 目标值不同，但各自段内稳定性同样 ≤5% |
| UI 背光亮度 | 25 / 50 / 75 | L_ref_white 整体平移，动态稳定性不变 |
| 环境光 | 开启，300 lux | 环境光响应与动态画面叠加，203 仍稳定 |

**I-4 画面内多点对比（可选，用多探头）**：

若有多探头，在不同位置（左上/右上/左下/右下/中心）各放一个 5% 203 nit 窗口同时测量，对比各点 L̄：
- 验证均匀性（边缘 vs 中心偏差 ≤15%）；
- 验证 Local Dimming 在动态画面下是否引起窗口间亮度差异（光晕/串扰）。

#### 与静态测试的对比

测试完成后，将 I-1 的 L̄ 与用例 D（静态灰阶 203 nit 实测值）对比：
- 若两者偏差 ≤3% → 动态画面下 TMO 联动正确，内容亮度与静态一致；
- 若偏差 >5% → 存在 APL 联动问题（背光变化未正确同步到 TMO，或时域滤波介入），需排查。

### 用例 H — 功率与能效

**验证**：文档"能效模式"与 Rtings 应对策略。

**前置**：功率计接入。

| 步骤 | 模式/信号 | 测量 | 判定 |
|---|---|---|---|
| H1 | 标准模式、10% 窗口 1000 nit PQ、UI=100 | 功率 P_peak | 记录峰值功耗 |

## 6. 补充说明

- **预热要求**：所有亮度测量在电视预热 30 分钟后进行，避免背光冷态偏差；
- **探头位置**：窗口测试探头对准窗口中心；全屏测试可多探头并行测均匀性；
- **环境光测试**：可调光源需均匀照射电视环境光传感器（非屏幕），用独立照度计确认传感器处实际 lux；
- **信号确认**：每次切换信号后，先用 CA-410 确认图案发生器输出正确（如 203 nit 信号实测应接近预期，排除信号链路错误）；
- **数据量**：完整测试约 8 用例 × 5–10 点 × 多模式/UI 组合 ≈ 150–200 个测量点，多探头可缩短至 1–2 天。
