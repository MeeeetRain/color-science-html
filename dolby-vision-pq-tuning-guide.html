环境搭建 完整流程
Overview

调参全景：四大阶段

一台 Dolby Vision 合规电视的画质调参，需依次完成测量、验证、全局调光、消费者偏好四个阶段。每个阶段的产出是下一阶段的输入。

PHASE 1 显示特性测量 测 Tmax / Tmin / TPrimaries / TEOTF，生成 VSVDB
PHASE 2 客观 + 主观验证 自动客观验证、手动客观验证、主观对比拍摄
PHASE 3 全局调光验证 背光同步测试、元数据到背光映射验证
PHASE 4 消费者偏好调参 亮度 / 对比度 / 暗部细节 / 色彩增强主观调参
SUBMIT 提交 Dolby 打包测试结果与配置文件，提交 Dolby 审核
前置条件：开始前请确认已具备 Unigraf UCD-323（固件 0.22.205 / TSI Lite 0.12.27 / Bundle 1.8.28）、被测 TV、安装好 PQ Kit 的 Windows 控制电脑（≥20GB 可用空间）、以及被测 TV 的 E-EDID 二进制文件。

Signal Generation

测试信号生成

用 callerScript.exe 或 dvsg 工具，基于被测 TV 的 E-EDID 生成 sink-led 与 source-led 两套测试信号。客观与主观验证都依赖这些信号。

一键生成

callerScript.exe

位于 <SDK>\Test_Tools\callerScript.exe。运行后会自动安装 dvsg 并生成全部 sink-led 测试信号（客观 + 主观）。适合首次搭建环境时使用。

每次运行会在 Test_Tools 下生成日志文件，可能耗时数分钟。
单独生成

dvsg 工具

已安装 dvsg 后，可单独生成 source-led 信号（用于主观验证）。需指定 TV 的 E-EDID 与 tcs_src_led.json 配置。

Sink-Led 客观测试信号生成

首次运行 callerScript.exe 会同时安装 dvsg 并生成 sink-led 信号。命令：

callerScript.exe — 以管理员身份运行
cd <SDK>\Test_Tools
callerScript.exe --tools <SDK>\Test_Tools\scripts\tools --ifs <SDK>\Test_Vectors\Dolby_Vision\HDMI\Infoframes --tbs <SDK>\Test_Vectors\Verification\HDMI\cfg\tbs.json --tcs <SDK>\Test_Vectors\Verification\HDMI\cfg\tcs_sink_led.json -o <SDK>\Test_Vectors\Verification\HDMI\Video --check-cfg 0 --hdmi-edid <EDID绝对路径>

Source-Led 主观测试信号生成

用于主观验证。关键是把 --tcs 指向 tcs_src_led.json，并指定 TV 的 E-EDID。

dvsg — 生成 SourceLed_Subj 信号
dvsg --log dvsg.log --tools <SDK>\Test_Tools\scripts\tools --ifs <SDK>\Test_Vectors\Dolby_Vision\HDMI\Infoframes --tbs <SDK>\Test_Vectors\Verification\HDMI\cfg\tbs.json --tcs <SDK>\Test_Vectors\Verification\HDMI\cfg\tcs_src_led.json -o <SDK>\Test_Vectors\Verification\HDMI\Video --check-cfg 0 --hdmi-edid <EDID绝对路径>

输出位置

信号输出到：<SDK>\Test_Vectors\Verification\HDMI\Video\SourceLed_Subj_v5.0\

含 Video\（46 个 bin 文件）、Event\（Infoframe 包）、SourceLed_Subj_v5.0.json。

播放场景文件

用 UCD-323 加载场景文件播放：<SDK>\Test_Vectors\Verification\HDMI\Scenarios\PQ_Sub_SourceLed_v5.0_FHD24.txt

每次重新运行命令会覆盖输出目录中的 bin 文件。

验证成功：命令行无错误信息即成功；日志中应出现 "HDMI signals successfully generated" 或 "Test signal generation completed"，并显示识别到的 EDID 与自动生成的 VSVDB 文件名。
常见错误：Insufficient storage space = 磁盘不足 20GB；MP4 复用失败 = 文件路径过长，日志会记录出错文件路径。

dvsg 参数速查

参数作用取值

Phase 1 · Measurement

显示特性测量

通过标准动态范围（SDR）数据通路测量面板特性——峰值亮度、最低亮度、基色与白点色度、Gamma。这些值构成 Dolby Vision 配置与 VSVDB 的基础。测量必须在 Dolby Vision 处理之前进行。

对应文档：Tuning Guide 第 3.1 节 "Measuring display characteristics"（PDF 第 17 页）。

第一步：准备 TV 设置

测量前，按 TV 类型设置如下，确保测量的是面板的真实物理特性：

TV 类型设置要求
所有 TV背光设为最大；后端处理保持与 Dolby Vision Dark picture mode 一致
局部调光 LCD背光最大 + 开启局部调光
全局调光 LCD背光最大 + 关闭 TV 全局调光
OLEDOLED 亮度（背光等效项）设为最大

第二步：用 JPG 测试图测量

SDK 自带 14 张 SDR 测试图（JPG），位于：

测试图目录
<SDK>\Test_Vectors\Display_property_measurement\Generic_pattern_generator\

用任意信号发生器（或 TV 自带的图片播放功能）依次显示这 14 张 JPG，用色彩分析仪 / 光度计测量每张图**中心色块**的光输出 XYZ：

文件名画面测量位置用途
FHD_L32_01R.jpg黑底 + 中心红色方块方块中心红色基色 xy
FHD_L32_02G.jpg黑底 + 中心绿色方块方块中心绿色基色 xy
FHD_L32_03B.jpg黑底 + 中心蓝色方块方块中心蓝色基色 xy
FHD_L32_Gray_000.jpg黑底 + 中心黑色方块方块中心最低亮度 Tmin（Y 值）
FHD_L32_Gray_010.jpg10% 灰背景 + 中心 10% 灰方块方块中心Gamma 曲线数据点
… _020 ~ _090对应灰度背景 + 中心同灰方块方块中心Gamma 曲线数据点
FHD_L32_Gray_100.jpg白底 + 中心白色方块方块中心峰值亮度 Tmax（Y 值）

共 3 张基色 + 11 级灰阶 = 14 张图。每张只需测量中心色块的光输出 XYZ（忽略背景区域）。基色图背景为黑色，灰阶图背景与方块同灰度。

对应文档：Tuning Guide 3.1 节原文："Primary and white point chromaticity are measured with full-scale red, green, and blue and 100% white level center boxes with the same gray background as in gamma measurement."
注意：JPG 测试图仅适用于"SDR 播放时不降低亮度或色域"的 TV。若 TV 在 SDR 下会主动压低亮度/色域，需改用 UCD-323 播放对应测试向量。

第三步：填写 Primary_gamma_v4.3.xlsx

下载下方表格，填入测量数据，其余工作表会自动计算。

⬇ 下载 Primary_gamma_v4.3.xlsx

填写规则（重要）

你的数据格式填在哪里单元格范围
XYZ 三刺激值（推荐，光度计直接输出） Raw Data 工作表的白底单元格 B2:O4
xyY 色度+亮度 直接覆盖填入，白底单元格留空 B5:O7
XYZ 格式

填 B2:O4

第 2 行 = X 值，第 3 行 = Y 值，第 4 行 = Z 值。列 B–O 对应 14 张图（3 基色 + 11 级灰阶，顺序与上表一致）。

xyY 格式

填 B5:O7

第 5 行 = x 色度，第 6 行 = y 色度，第 7 行 = Y 亮度。B2:O4 必须留空，否则会冲突。

自动计算：数据填入后，表格其余工作表（含 Measurement data）会自动填充，无需手动计算。

VSVDB 生成与验证

测量值通过 dtv_config_lib_test.exe 写入配置二进制，并生成 VSVDB 字符串写入 EDID。dvsg 生成信号时会自动读取 EDID 中的 VSVDB 并生成对应的 <EDID名>_vsvdb.bin。

dtv_config_lib_test.exe — 生成配置二进制
dtv_config_lib_test.exe -v dvp|dm4 -t xxx.cfg -b xxx.bin [-vsvdb]

支持的 DM 版本：dvp（DMv3.0 / profile 1）与 dm4（DMv4.0 / profile 5/7）。

Configuration

PQ 配置文件

PQ 配置文件（.cfg / .bin）定义了 TV 的全局参数与各 picture mode 参数。通过 PQ 调参工具编辑，经 ADB 推送到 TV。

Global

全局参数 [Global]

面板特性、背光、光感、暗部细节、系统、VSVDB 等，对所有 picture mode 生效。

PictureMode

Picture Mode 参数 [PictureMode=N]

各画质偏好（亮度/对比度/饱和度/背光）、元数据引导参数（gain 系列）、风险曲线参数。

配置文件工作流：SDK 支持 text（.cfg）与 binary（.bin）两种工作流。text 流程：编辑 .cfg → dtv_config_lib_test.exe 生成 .bin → ADB push 到 TV。详见 DeviceConfigFileSpec 附录 B。

跨 DM 版本映射

不同 Display Management 版本（DMv3 / DMv4）参数有差异，DeviceConfigFileSpec 附录 A 提供了参数映射表，迁移配置时参考。

Tuning Tool

PQ 调参工具操作

PQ 调参工具（dlb_app_dvpq）是 GUI 程序，通过 ADB 连接 TV，编辑/推送/拉取 PQ 配置参数。

配置平台 JSON

打开 <SDK>\Test_Tools\dlb_app_dvpq\ 下的样例配置。v1.1 平台用 sample_platform_cfg_adb_v1_1.json，否则用 sample_platform_cfg_adb_v1_0.json。按 TV 平台实际情况修改 ADB 命令、配置路径、picture mode 映射等。

启动调参工具

运行 dlb_app_dvpq 可执行文件。在 UI 中点击 Select Platform Configuration 加载刚编辑的 JSON，工具会通过 ADB 连接 TV。

编辑参数

UI 左侧显示参数列表，可用 slider 或直接输入数值编辑。支持 Global 与各 PictureMode 参数切换。

Push 到 TV（Ctrl+X）

编辑完成后按 Ctrl+X 或点 Push 按钮，参数经 ADB push 到 TV 并激活，TV 画面实时变化。

Pull 保存

从 TV 拉取当前生效的配置保存到本地，用于备份或对比。

Troubleshooting

故障排查

常见问题与解决方案，覆盖环境、连接、信号、调参工具各环节。

dvsg 安装失败：meson 编译 numpy 报错？
dvsg 依赖 numpy<2.0，Python 3.13 无预编译包且本机无 VS 编译环境。改用 Python 3.12 安装：py -3.12 -m pip install ...whl。dvsg.exe 会装到 %APPDATA%\Python\Python312\Scripts\，需手动加入 PATH。
dvsg 报 "Insufficient storage space"？
磁盘可用空间不足 20GB。清理后重试。信号生成会占用大量临时空间。
dvsg 报 MP4 复用失败 / 文件路径过长？
Windows 路径长度限制。把 SDK 解压到较短的根目录路径（如 C:\Dolby\），避免深层嵌套。日志会记录出错的文件路径。
PQ 调参工具连不上 TV？
①确认 TV 已开启 ADB 调试；②adb connect <ip>:<port> 手动测试；③检查平台 JSON 中 IP/端口/命令是否正确；④v1.1 平台用 pre_cmd_delay_seconds 处理响应延迟；⑤参考 Tool User Guide 第 5 章故障排查表。
dvpqReadTargetVersion 未实现导致功能受限？
这是平台 API，若未实现，调参工具部分功能受限。需在平台 JSON 中实现 readTargetVersionCmd（adb shell 命令），返回 TV 软件版本。
Tmin 测量失败？
参考 Tuning Guide 的设备连接示意图与光感客观验证环境指引。检查：光度计连接、消除环境杂光、确认 TV 处于 Dark picture mode、光度计量程合适。
生成信号后 TV 显示不对 / VSVDB 不匹配？
确认使用的 E-EDID 是被测 TV 当前抓取的。不同型号 TV 必须用各自 E-EDID 重新生成。重新抓取 EDID 后重跑 dvsg 命令。
全局调光 parse_data.exe 报错？
需安装 MATLAB Runtime R2020b。确认运行时已正确安装且版本匹配。
read_USB_port.py 报错找不到串口？
需 pip install pyserial。确认 USB 光度计已连接且驱动正常，检查设备管理器中的 COM 端口。
