Camera Log Encoding

为什么相机使用 Log 拍摄

Log 不是把画面调灰，也不是万能动态范围按钮。它是相机把线性传感器数据压进有限码值时，为高光、阴影、18% 灰和后期调色做出的编码设计。

1. Log 先解决“码值怎么分”

传感器接收光是近似线性的：亮一档，光量翻倍。如果直接线性记录，最亮的一档会吃掉一半可用码值，而暗部很多档会挤在很小的范围里。Log 的核心，是按“曝光档位”重新分配码值。

直觉：Log 不是创造更多动态范围，而是让相机已经捕获到的动态范围更适合被 10/12 bit 编码、监看、调色和交换。
传感器
线性

光量翻倍，信号翻倍。高光天然占用更多数值空间。

把每一档曝光分得更均匀，暗部与高光都保留可调空间。

锚点
18%

中灰位置是现场曝光、假色、波形和后期还原的共同参照。

色域
Gamut

Log 曲线通常必须和对应广色域一起使用，不能只选 Gamma。

2. 厂商设计 Log 时在取舍什么

各家 Log 曲线看起来都“灰”，但设计目标不一样。ARRI LogC4 重视 12 bit 编码精度和 EI 无关解码；Sony S-Log3 靠近 Cineon 负片扫描习惯；Canon 把 Log 2 和 Log 3 分成不同后期负担；Panasonic V-Log 让 Varicam 与 LUMIX 保持一致；RED 把 Log3G10 放进 IPP2 管线。

判断一个 Log，不要只问“有几档”。更重要的是：中灰落点、黑位处理、高光余量、色域搭配、位深要求和输出变换。

中灰不是随便放

18% 灰如果放得高，暗部有更多码值但高光空间变少；放得低，高光更宽但监看更暗。Sony S-Log3 和 Panasonic V-Log 都把中灰放在约 41-42 IRE 附近，Canon Log 3 更低一些。

黑位需要一段“脚趾”

很多曲线在极暗部不是纯对数，而是线性或缓变段。这样能避免数学奇点，也能控制噪声、量化和负值处理。

广色域才是另一半

Log 负责亮度编码，Gamut 负责颜色边界。S-Log3 通常配 S-Gamut3.Cine，LogC4 配 AWG4，V-Log 配 V-Gamut，Log3G10 配 REDWideGamutRGB。

ARRI LogC4 的关键变化

LogC4 是 LogC3 的后继，用于 ARRI REVEAL / ALEXA 35 等流程。它的正式曲线是 EI 无关的，解码不需要根据拍摄 EI 换函数；ARRI 也明确指出 LogC4 以 12 bit 编码为最低量化目标，10 bit 不应用于归档或交换。

LogC4 编码核心：
E' = ((log2(a · E + 64) - 6) / 14) · b + c
其中 E 是相对场景线性值，18% 灰约映射到 0.278。

S-Log3 的设计味道

Sony 官方技术资料把 S-Log3 描述为更接近“纯 Log / Cineon 工作流”的曲线：中灰比 S-Log2 更亮，暗部 toe 减少，高光动态范围比 S-Log2 延展约 1.5 档。S-Gamut3.Cine 则略宽于 DCI-P3，便于影视调色。

S-Log3 公开公式锚点：
18% 灰 → 约 41% / 10bit CV 420
90% 白 → 约 61% / 10bit CV 598

4. 各家 Log 不是同一种“灰”

不同厂商的 Log 不是随意调一条低反差曲线，而是围绕传感器、位深、监看 LUT、输出变换和自家色彩科学做的一整套设计。

实操时要同时选择 Input Gamma 和 Input Color Space。只写“S-Log3”或“C-Log3”还不够，通常还要写 S-Gamut3.Cine、Cinema Gamut、V-Gamut、AWG4 等。

Canon Canon Log 2 / Log 3 + Cinema Gamut Log 2 偏最大动态范围与暗部层次；Log 3 偏易用性和高光延展。 Canon 官方资料按 10% 或 18% 灰给出曲线与相对档位；Log 3 常见中灰约 34%。 Log 2 后期空间大但暗部噪声更明显；Log 3 更适合一般制作。
Panasonic V-Log + V-Gamut 源自 VariCam，强调跨机型一致的 14+ 档宽容度与 V709 监看/转换。 18% 灰约 42 IRE / 10bit CV 433；90% 白约 61 IRE。 V-Log L 与完整 V-Log 可编码范围不同，调色时先确认机型和元数据。
RED REDWideGamutRGB + Log3G10 IPP2 把 RAW 开发、Log 工作空间、输出变换分层；Log3G10 以灰上 10 档作为上限设计。 18% 灰约 1/3；灰上 10 档接近 1.0。 调色时区分 Legacy 与 IPP2；输出变换不是普通 LUT 装饰，而是显示适配的一部分。
Blackmagic Blackmagic Film / Gen 5 或 DaVinci Wide Gamut Intermediate 围绕 Resolve 色彩管理和 BRAW 元数据工作；常把相机 Log 转到宽色域中间空间再调色。 不同机型与 Gen 版本不同。 确认 Gen 4 / Gen 5、BMD Film 与 DWG Intermediate，别只看“Film”字样。

5. 正确使用 Log 的流程

Log 的价值在于保留场景信息，但它要求更严格的流程：曝光不能只看“画面灰不灰”，监看要加正确变换，后期要先做技术转换，再做创意调色。

Log 工作流不是“拍灰，再加对比度”。它应该是：识别输入 → 转换到工作空间 → 调色 → 输出到目标显示。
拍摄

按中灰和高光曝光

用波形、假色、斑马或监看 LUT 判断。中灰落点要按曲线查官方值，高光不要靠“后期能拉回来”赌博。

监看

使用官方或可信 LUT

现场监看 LUT 是显示变换，不应该改变记录素材本身。给导演和摄影看正常画面，同时保留 Log 原始记录。

后期

先技术转换

在 Resolve、ACES 或 OCIO 中指定正确 Input Gamma / Gamut。确认 LogC4、S-Log3、V-Log 等输入没有选错。

输出

按目标显示交付

Rec.709、P3、PQ HDR、HLG 的输出变换不同。最终画面好不好，取决于输出端适配，而不是 Log 曲线本身。

什么时候适合拍 Log

高反差场景、广告/短片/电影、需要风格化调色、需要与多机位色彩管理统一时，Log 很有价值。

什么时候不要硬拍 Log

8 bit 低码率、极低照度、快速交付、没有监看 LUT 或没有后期转换能力时，普通视频 Gamma 或 HLG 可能更稳。
