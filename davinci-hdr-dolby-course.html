HDR 与 Dolby Vision 制作

制作概念、项目设置、HDR 母版流程和 Dolby Vision 元数据流程。

课前预习

02 / Objectives

先掌握五件事

  • 素材的 Gamma / Gamut 必须先被正确解释。
  • 调色发生在时间线工作空间，不直接等于最终显示空间。
  • PQ HDR master 是 display-referred 交付目标。
  • HDR10 使用静态元数据；Dolby Vision 使用动态元数据和 trim。
  • 监看链路、示波器读法和导出设置必须一致。
03 / Pipeline

HDR 制作链路

1

素材

确认 Log / RAW / Rec.709，以及对应的输入 Gamma 和 Gamut。

2

工作空间

进入 DaVinci Wide Gamut Intermediate 或 ACES。

3

监看

设置 Rec.2100 ST2084 / PQ 输出和 HDR 参考显示器。

4

调色

完成镜头匹配、曝光、白平衡、对比和高光分配。

5

检查

检查波形、CIE、MaxCLL / MaxFALL、字幕和高饱和色。

6

交付

输出 HDR master、HDR10 元数据或 Dolby Vision 元数据。

04 / Concepts

四个概念必须分开

Input
素材

相机文件当前如何编码，不能只看画面是否发灰。

Timeline
工作

调色计算发生的空间，建议使用 DWG Intermediate 或 ACES。

Output
监看

通过 Output Transform 生成 Rec.709、PQ HDR 或其他显示目标。

Delivery
交付

导出文件、元数据、编码器和平台要求属于最后一层。

05 / Resolve Setup

Scene-referred 时间线设置

Input

按素材指定相机 Log / Gamut，例如 S-Log3 / S-Gamut3.Cine、LogC4 / AWG4、BRAW Gen 5。

Timeline

使用 DaVinci Wide Gamut / DaVinci Intermediate，或 ACEScct。不要把 Timeline 直接设成 Rec.2100 PQ。

Output

HDR 母版输出设 Rec.2100 ST2084；SDR 版本输出设 Rec.709 Gamma 2.4。

Timeline 是调色计算空间；Output 才是显示目标。同一条时间线可以输出 HDR、SDR 或 Dolby Vision 版本。
06 / Multi-camera Input

不同摄影机素材的色彩管理

Project Default

默认输入设主机位

如果主机位占比最高，可以把项目默认 Input Color Space / Gamma 设为主机位的 Log / Gamut。

Clip Override

其它机位手动指定

副机位、无人机、运动相机、素材包等，在 Media Pool 或 Color 页按 clip 指定正确输入色彩空间。

Same Timeline

统一进入同一时间线

每种输入先被转换到 DWG / Intermediate 或 ACEScct，再进行镜头匹配和整体调色。

主机位

Project Input：例如 Sony S-Log3 / S-Gamut3.Cine。

副机位

Clip Input：例如 Canon Log 3 / Cinema Gamut、DJI D-Log、ARRI LogC4 / AWG4。

判断顺序：先做输入色彩管理，再做镜头匹配。不要用白平衡、曲线或 LUT 去补偿错误的 Input Color Space。
07 / Log vs PQ

Log 和 PQ 不是同一层

项目
Log / RAW 素材
PQ HDR Master
性质
Scene-referred 或接近 scene-referred。
Display-referred，码值对应绝对显示亮度。
用途
保留拍摄动态范围，等待显示转换和调色。
作为 HDR 显示目标和交付母版。
错误做法
把 Log 当低对比度成片直接调。
把 PQ 当相机编码或工作空间。
08 / HDR Master

HDR master 要检查什么

  • 普通白、字幕白、肤色和镜面高光应有不同亮度位置。
  • 1000 nit 是常见母版峰值，不是画面整体亮度目标。
  • 高饱和高亮颜色需要检查色域压缩和 hue shift。
  • 暗场需要检查黑位、噪声、局部调光和压缩风险。
  • MaxCLL / MaxFALL 是交付信息，不替代画面判断。
09 / Delivery

SDR、HDR10、Dolby Vision

SDR

Rec.709 / Gamma 2.4

100 nit 参考显示，亮度范围小，兼容性最高。

HDR10

PQ + 静态元数据

整片一组 mastering display、MaxCLL 和 MaxFALL。

Dolby Vision

PQ + 动态元数据

逐镜头或逐帧分析，并通过 trim 指定目标显示映射。

10 / Resolve Setup

达芬奇项目设置

Color Management

项目级色彩管理

1
Input

为每种素材指定正确 Input Color Space / Gamma。

2
Timeline

使用 DaVinci Wide Gamut / Intermediate 或 ACEScct。

3
Output

HDR 输出设 Rec.2100 ST2084；SDR 输出设 Rec.709 Gamma 2.4。

Monitoring

监看链路

1
Video I/O

优先通过 DeckLink / UltraStudio 输出到参考显示器。

2
Display

确认白点、峰值亮度、EOTF、色域和限幅状态。

3
Scopes

确认波形单位和 HDR 标尺读法。

11 / Grade Order

HDR 调色顺序

  • 先做技术设置，再做主观调整。
  • 先匹配镜头，再建立整体风格。
  • 先控制曝光和对比，再处理局部高光。
  • 先检查肤色和中性灰，再检查高饱和颜色。
  • 先完成 HDR master，再进入 Dolby Vision。
12 / Dolby Vision

Dolby Vision 多了什么

Analysis

分析 HDR 母版

读取 HDR grade 的亮度和色彩分布，生成基础动态元数据。

Trim

目标显示修正

针对 100 nit SDR、600 nit、1000 nit 等目标显示调整映射结果。

Metadata

交付元数据

通过 XML、RPU 或封装文件进入编码、平台和播放链路。

13 / Dolby Vision Workflow

Dolby Vision 制作流程

  • 完成 PQ HDR master。
  • 执行 Dolby Vision analysis。
  • 选择目标显示并检查自动映射结果。
  • 对关键镜头做 trim。
  • 导出 metadata，并检查时间线、版本和封装要求。
14 / EL & Profiles

增强层 EL 和 Profile 选择

BL

Base Layer

基础视频层。Profile 8.1 是 HDR10 兼容，8.4 是 HLG 兼容。

RPU

动态元数据

记录 Dolby Vision 映射信息。5.0、8.1、8.4 都是单层 + RPU。

EL

Enhancement Layer

Profile 7 UHD Blu-ray 双层工作流才涉及 EL，普通导出通常没有。

5.0单层 + RPU

纯 Dolby Vision；没有 HDR10 fallback。

8.1HDR10 BL + RPU

PQ / BT.2020；非 DV 设备可按 HDR10 播放。

8.4HLG BL + RPU

HLG 兼容；常见于广播或 HLG 文件。

7BL + EL + RPU

UHD Blu-ray 双层；MEL/FEL 需授权编码流程。

15 / QC

QC 重点

技术合法

信号范围

检查 clipping、非法码值、色域越界、MaxCLL / MaxFALL 和元数据一致性。

目标版本

映射结果

检查 SDR、HDR、600 nit、1000 nit 等目标版本的暗部、高光和肤色。

常见风险

逐镜头检查

字幕过亮、暗场压死、转场元数据不连续、高饱和高光偏色。
