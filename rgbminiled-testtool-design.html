RGB MiniLED 电视画质测试工具 设计说明 v0.1

面向 RGB MiniLED 背光电视的 串色 与 动态画面色域缩小 两类缺陷 · 测试图卡生成器 + 测量分析流水线 · 指标锚定 IDMS / CIE D50 CIELAB 色域体积 + Gamut Rings

一、要解决什么问题

RGB MiniLED 把背光从"白光 + 彩膜"升级为独立驱动的 R/G/B 分区——色域与亮度大涨， 但也把"亮度型 blooming"升级成了两类新缺陷：

① 串色 / 彩色光晕 Colour Crosstalk

本质：色度的空间光晕。白点在彩色背景里发品红/发青，肤色上出现彩色镶边。

  • 背光空间分辨率 ≪ LCD 像素 → 分区背光是"折中混合色"
  • 光学串扰（PSF 侧向漏光）→ 邻区互染
  • LED 发射光谱与彩膜通带失配 → 色偏
  • 三通道局部调光反演误差

② 动态色域缩小 Dynamic Gamut Shrink

本质：色域随 APL / 背景 / 运动 收缩——静态色块漂亮、动态内容缩水。

  • 功率/热限制（ABL）→ 高 APL 下峰值彩色亮度回退
  • 局部调光色度折中 → 复杂画面到不了满饱和
  • 时序动态/压摆率 → 瞬态掉饱和、拖影
  • 动态色调/色域映射（DTM）压缩

二、测试指标

串色指标

指标定义
色串扰半径 R_cross沿剖线，应为纯色区相对目标的 Δu'v' 衰减到阈值(默认0.01)前的最远距离
峰值染色中性/暗区被邻色污染的 Δu'v'ₘₐₓ / ΔE_ITPₘₐₓ
二维 Δu'v' 热力图全场色度偏差分布（CXC-2600 直接出）
背光 PSF FWHMR/G/B 单点点扩散半高宽（分通道）
棋盘污染 / 边缘镶边各格 Δu'v'、ANSI 对比；异色硬边色过冲

动态色域指标

指标定义
CIELAB-D50 色域体积实测壳点(RGBCMYW+黑)凸包体积，按固定峰值白点归一
BT.2020 / P3 覆盖率逐 L* 切片的环交覆盖
Gamut Rings按 L* 切片的 a*b* 截面积分布（色域示波器）
动态色域收缩率 (KPI)1 − vol(大窗/高APL) / vol(小窗/低APL)
color-in-context同色块随背景 APL 升高的掉饱和
关键设计：色域体积按固定峰值白点归一（而非逐窗白点），于是 ABL 亮度回退会真实地表现为体积收缩——这正是量化"静态漂亮、动态缩水"的抓手。
